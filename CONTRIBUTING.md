# Contribution Guidelines

Thank you for checking out this project! This repository hosts my project for the Develop the Future co-op and my eventual submission for the Apple Swift Student Challenge.

## Code Contributions

Because this project must be developed entirely by an individual student to comply with the Swift Student Challenge guidelines, any commits and pull requests **cannot** be accepted.

## How to Help

While I can't accept code changes, I would love any feedback or guidance!

If you are a mentor or peer, please help by opening an issue with your bugs, feedback, or suggestions.
